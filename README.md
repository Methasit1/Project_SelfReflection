# Self-Reflection & Tracking System
### ระบบบันทึกสภาวะอารมณ์และทบทวนตนเอง

> โครงการวิศวกรรมซอฟต์แวร์ (Software Engineering Project)  
> สาขาวิชาวิศวกรรมซอฟต์แวร์ คณะเทคโนโลยีสารสนเทศและการสื่อสาร มหาวิทยาลัยพะเยา

---

## เกี่ยวกับโปรเจกต์ (Project Overview)

**Self-Reflection & Tracking System** เป็นเว็บแอปพลิเคชันที่ช่วยให้ผู้ใช้งานสามารถสำรวจอารมณ์ ประเมินปัจจัยกระตุ้น และตกผลึกความคิดของตนเองในแต่ละวันได้อย่างเป็นระบบ โดยประยุกต์ใช้แนวคิดกระบวนการสะท้อนคิด **Gibbs' Reflective Cycle (1988)** ปรับให้อยู่ในรูปแบบดิจิทัลที่ใช้งานง่าย ลดอุปสรรคในการเริ่มต้นเขียนบันทึกด้วยชุดคำถามชี้นำจากคลังคำถามจิตวิทยามาตรฐาน (Certified Question Bank)

### ฟีเจอร์หลัก (Key Features)

- **Guided 3+1 Step Daily Tracker:**
  1. **Emotion Survey:** ประเมินระดับอารมณ์ประจำวัน 5 ระดับ
  2. **Trigger Identification:** ระบุเหตุการณ์หรือปัจจัยกระตุ้น
  3. **Reaction Observation:** สังเกตปฏิกิริยาทางร่างกาย ความคิด หรือพฤติกรรม
  4. **Reflection & Insight:** สุ่มดึงคำถามจิตวิทยาที่เหมาะสมกับสภาวะอารมณ์มาแสดง เพื่อสร้างการตกผลึกความคิด
- **Rule-Based Question Selection Engine:**
  - สุ่มคำถามชี้นำจากคลังคำถามที่ผ่านการรับรองตรงตามหมวดหมู่อารมณ์
  - ระบบกรองคำถามซ้ำ ไม่ให้ซ้ำกับคำถามที่เคยได้รับใน 3 รายการบันทึกล่าสุด
- **Interactive Mood Calendar:**
  - แสดงภาพรวมสภาวะอารมณ์รายเดือนในรูปแบบปฏิทิน (อ้างอิงตาม Entry Date)
  - ย้อนดูบันทึกรายละเอียดความคิดและการตกผลึกย้อนหลังได้
- **Crisis Keyword Detection & Psychological Safety:**
  - ตรวจจับคำเสี่ยงอันตรายในกล่องข้อความแบบ Real-time (Server-side Search)
  - แสดงแบนเนอร์แนะนำ **"สายด่วนสุขภาพจิต 1323"** ทันทีเมื่อพบคำเสี่ยง โดยไม่เก็บบันทึกประวัติเพื่อความเป็นส่วนตัวสูงสุด (100% Psychological Safety)
- **Late-Night & Draft Management:**
  - รองรับการบันทึกย้อนหลังช่วงดึก (00:01 - 05:00 น.)
  - รองรับการค้างร่างข้อมูลชั่วคราว (Draft State) ใน `localStorage`

## เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** Next.js / React, Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL 16+)
- **Authentication:** Supabase Auth
- **Deployment:** Vercel / Netlify

---

## โครงสร้างฐานข้อมูล (Database Schema)

ระบบประกอบด้วย 6 ตารางหลักบน PostgreSQL (Supabase):
1. `users` — ข้อมูลผู้ใช้งานและบริบท Onboarding
2. `daily_entries` — ข้อมูลการบันทึกประจำวัน (Emotion, Trigger, Reaction)
3. `questions` — คลังคำถามจิตวิทยามาตรฐาน (Certified Question Bank)
4. `question_history` — ประวัติการสุ่มคำถาม (ใช้กรองคำถามซ้ำ 3 ครั้งล่าสุด)
5. `reflection_logs` — ประวัติการตกผลึกความคิด (Step 4 Reflection)
6. `crisis_keywords` — คลังคำเสี่ยงสำหรับตรวจจับเพื่อแสดงสายด่วนช่วยเหลือ
